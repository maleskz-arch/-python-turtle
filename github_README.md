# Python Turtle — от первой линии до цифрового узора

Готовый комплект для GitHub Pages, репозиторий `maleskz-arch/techverse`.

## Какие файлы разместить

- `masterclass.html` — ученический сайт: последовательное создание одного рисунка, теоретические блоки, задания, скрытые решения, рисунки этапов.
- `teacher.html` — подробное пособие преподавателя, ответы, тайминг и дополнительные пояснения библиотеки Turtle. Можно открыть в браузере — скачивать отдельно не нужно.

Файлы **самодостаточны**: изображения встроены внутрь `masterclass.html`; дополнительных папок `images`, `css` или `js` не требуется. Интернет понадобится для запуска Python в Coddy, который открывается отдельно.

## Загрузка в GitHub Pages (веб-интерфейс)

1. Откройте GitHub → репозиторий `maleskz-arch/techverse`.
2. Перейдите во вкладку **Code** (корень репозитория). Если `masterclass.html` уже есть, он будет заменён при добавлении нового одноимённого файла и фиксации изменений.
3. Выберите **Add file → Upload files**.
4. Загрузите **распакованные** `masterclass.html` и `teacher.html` из этого архива. Сам ZIP загружать не нужно: GitHub не распакует его автоматически как сайт.
5. Нажмите **Commit changes**. Для обновления существующего файла через интерфейс GitHub, если он не принимает замену при загрузке, откройте файл в репозитории, выберите редактор или сначала удалите старую версию отдельным коммитом; затем загрузите новую.
6. Проверьте, что GitHub Pages настроен на ветку и папку, содержащую оба HTML-файла (обычно `main` / `/ (root)`). При необходимости: **Settings → Pages**.

## Адреса после публикации

Ученический сайт:
https://maleskz-arch.github.io/techverse/masterclass.html

Материалы преподавателя:
https://maleskz-arch.github.io/techverse/teacher.html

Урок с подсказками для ведущего (используйте на своём экране):
https://maleskz-arch.github.io/techverse/masterclass.html?teacher=1

Coddy:
https://coddy.tech/playground/ru/turtle

**Важно:** содержимое `teacher.html` в публичном GitHub Pages доступно любому, кто знает или угадает адрес. Если решения должны быть закрыты от учеников, храните пособие в приватном месте, а не на публичном сайте.

## Если обновления не видны

Подождите публикации GitHub Pages и обновите страницу с принудительной перезагрузкой (Ctrl+F5). Убедитесь, что загрузили файлы в публикуемую папку, а не в соседнюю директорию.
